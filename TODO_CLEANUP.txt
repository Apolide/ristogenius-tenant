/////////////// TESTING

usare il database di testing specifico altrimenti vengono eliminati dati dal db di sviluppo!!!!

- db di test viene creato da docker-compose-dev.yml con script sql di provisioning

puoi crearlo a mano se inesistente:
docker compose -f docker-compose-dev.yml exec ristopilot-tenant_database \
  mysql -uroot -proot \
  -e "CREATE DATABASE IF NOT EXISTS ristopilot_tenant_testing CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; GRANT ALL PRIVILEGES ON ristopilot_tenant_testing.* TO 'test'@'%'; FLUSH PRIVILEGES;"

puoi verificare se db e utente di test funzionano:

docker compose -f docker-compose-dev.yml exec ristopilot-tenant_database \
  mysql -utest -ptest \
  -e "SHOW DATABASES;"
